About GitHub Explorer

GitHub Explorer lets you search any public GitHub user and browse their repositories. Filter by language, sort by name or stars, and open any repo directly on GitHub.

  • Built with vanilla HTML, CSS & JavaScript
  • Uses the public GitHub REST API
  • Remembers your last search with localStorage
  • Fully responsive — works on mobile, tablet, and desktop
