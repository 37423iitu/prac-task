# GitHub Repository Explorer

Практическая работа: поиск публичных репозиториев пользователя GitHub.

## Возможности

- Поиск пользователя по логину и отображение профиля.
- Список публичных репозиториев, фильтр по языку программирования.
- Сортировка по названию и количеству звёзд.
- Сохранение последнего введённого логина в localStorage.
- Адаптивная навигация, состояния загрузки и ошибки.

## Запуск

Откройте `index.html` в браузере или через WebStorm: **Open in Browser**.
Установка пакетов и сборка не требуются. Для запросов GitHub нужен интернет.

Вариант запуска через локальный сервер из папки проекта:

```powershell
python -m http.server 8080
```

Затем откройте http://localhost:8080. Для остановки сервера нажмите Ctrl+C.

## Проверка вручную

1. Нажмите **Start Searching** и введите `37423iitu`.
2. Проверьте отображение профиля и публичных репозиториев.
3. Измените сортировку и фильтр языка.
4. Проверьте ошибку при пустом поле и некорректном логине.
5. Обновите страницу: последнее введённое имя должно сохраниться.

## Файлы

- `index.html` — структура страницы.
- `css/style.css` — оформление и адаптивность.
- `js/script.js` — запросы, фильтрация, сортировка и взаимодействие.

Используются HTML, CSS, JavaScript и публичный GitHub REST API.
Загружается до 100 репозиториев пользователя; токен GitHub не требуется.
